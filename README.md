# 待辦事項 ToDoApp

一個以「每日例行事項」為核心的輕量待辦 PWA。純前端、無框架、無建置步驟，資料全部存在瀏覽器本機（IndexedDB），可加入手機主畫面離線使用。

## 功能

- **今天清單**：只顯示今天該做、尚未完成的事項，標題列顯示剩餘數量。
- **滑動完成**：卡片向左滑露出「完成」按鈕，快速滑動或滑過 60% 直接完成；完成後可在提示中「復原」。
- **重複頻率**：每天、每週一次（本週任一天完成一次即可）、週間、週末、一三五、二四六。
- **類別配色**：運動、生活、教育、健康、娛樂、其他，各有卡片底色。
- **縮圖與圖片**：內建 9 種線條圖示；每個事項最多附 9 張圖片（自動縮小到 1280px、JPEG 0.85），詳情頁可點開燈箱瀏覽。
- **影片**：每個事項最多 3 部影片（單檔 100MB 以內），存在本機，詳情頁可直接播放。
- **置頂**：在詳情頁點圖釘，事項會固定在今天清單最上面。
- **拖曳排序**：長按卡片約 0.4 秒後上下拖曳調整順序（置頂與一般事項各自排序）。
- **事項詳情**：編輯、複製（同名事項可多份）、刪除。
- **一週總覽**：以表格列出每天要做的事項與每日合計，相同事項會合併並顯示 ×N。
- **備份 / 還原**：匯出為 JSON（圖片以 data URL 內嵌，影片不包含在備份內），支援系統分享；還原會取代目前全部事項，本機上的影片仍會保留給對應的事項。
- **App 圖示數字**：安裝為 PWA 後，可開啟通知權限，在主畫面圖示上顯示今天剩餘數量（支援 Badging API 的平台）。
- **自動更新**：Service Worker 比對檔案內容，有新版時在清單頁自動重新整理，其他頁面則提示「有新版本」。
- **跨日自動切換**：每分鐘及回到前景時檢查日期，跨日後清單自動重算。

## 檔案結構

```
index.html      頁面骨架（#app、toast、lightbox）
app.js          全部應用程式邏輯
style.css       樣式
sw.js           Service Worker：離線快取與更新檢查
manifest.json   PWA 設定
icons/          App 圖示（180 / 192 / 512）
```

## 本機執行

不需要安裝任何套件，只要用任一靜態伺服器提供此資料夾即可（Service Worker 需要 `http://localhost` 或 HTTPS，直接開檔案 `file://` 無法使用）：

```bash
npx serve .
```

或

```bash
python -m http.server 8000
```

然後在瀏覽器開啟對應網址。手機上用 Safari／Chrome 開啟後選「加入主畫面」即可當作 App 使用。

## 部署

把整個資料夾上傳到任何靜態網站主機（GitHub Pages、Netlify、Cloudflare Pages 等）即可。所有路徑皆為相對路徑，可放在子目錄下。

## 資料與隱私

- 所有資料只存在你的裝置上（IndexedDB 資料庫 `todoapp`），不會上傳到任何伺服器。
- App 會請求持久化儲存（`navigator.storage.persist()`），降低被瀏覽器自動清除的機會。
- 清除瀏覽器網站資料會刪除所有事項，建議定期使用「匯出備份」。
